Sobre a disciplina

A disciplina apresenta conceitos arquiteturais básicos da Web e trabalha o projeto e a implementação de sistemas Web. Durante o semestre, os estudantes desenvolvem aplicações cliente-servidor, conhecem tecnologias de frontend e backend e estudam comunicação assíncrona e acesso a bancos de dados.

Professor: Lucas Francisco da Matta Vegi

  • Código: INF321;
  • Carga horária semestral: 60 horas;
  • Carga horária semanal: 4 horas;
  • Créditos: 4 (2-2);
  • Dedicação semanal recomendada ao estudante: 2 horas;
  • Número máximo de vagas: 50 estudantes.

Conteúdo programático

A ementa oficial está organizada nos seguintes tópicos:

  1. Introdução à Web;
  2. Linguagens para desenvolvimento frontend (HTML, CSS e JavaScript);
  3. Linguagem para desenvolvimento backend com Elixir;
  4. Framework para desenvolvimento backend com Phoenix;
  5. Introdução a Middleware, com Plugs e Phoenix;
  6. Tópicos avançados em Web.

Metodologia

As aulas combinam explicações teóricas e atividades práticas em laboratório. Ao longo do semestre, os estudantes realizam exercícios, estudos e trabalhos em grupo, além de desenvolverem um sistema Web de forma incremental, passando pelas etapas de planejamento, implementação, testes e documentação.

Ferramentas utilizadas

O plano de ensino indica a utilização das seguintes ferramentas e tecnologias:

  • Visual Studio Code;
  • Linguagem Elixir;
  • Framework Phoenix;
  • Git;
  • Planilhas e editor de texto.
